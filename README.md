## Что в лаунчере?

- Поиск Geometry Dash в библиотеках Steam и ручной выбор папки. Текущая установка запускается через `steam://run/322170`; скачанная через DepotDownloader версия запускается из своей папки. Проверки доступа к игре остаются за Steam и самой игрой.
- При нажатии «Играть» запрос всегда передаётся клиенту Steam. 
- Открытие Steam для законной установки и обновления игры.
- Список модов Geode из папки `geode\mods`. По умолчанию открывается папка игры, которую запускает лаунчер; через список можно переключиться на папку версии прежнего лаунчера в `%LOCALAPPDATA%\GDLauncherSteam\versions`.
- Можно войти в свой steam. Логин сам по себе не подтверждает покупку: доступ к игре проверяет Steam.
- Кнопка на главной открывает каталог версий. 
- Русский и английский интерфейс; настройки хранятся в `%APPDATA%\OpenGDLauncher\settings.json`.
- Локальные темы из `Themes/<имя>/theme.json`, импорт ZIP в «Настройках», применение и удаление в «Мои темы».
- Темы теперь оформляют также плашку главной, строки модов, окно выбора версий, Steam-блок, поля ввода и звук персонажа. Шаблоны и подробная инструкция доступны кнопкой в «Настройках» и включены в тестовый архив.

## Сборка

Откройте `OpenGDLauncher.sln` в Visual Studio 2022 с компонентом **.NET desktop development** и .NET 8 SDK. Выберите `Release` и соберите решение. Альтернатива: `dotnet publish Launcher.UI/Launcher.UI.csproj -c Release -r win-x64 --self-contained false`.

Тема по умолчанию создаётся при первом запуске в `%APPDATA%\OpenGDLauncher\Themes`. Для самостоятельного распространения скопируйте всю папку публикации. Нужен установленный .NET 8 Desktop Runtime. Не переносите папку `.dotnet`, если она есть в исходном проекте: это только локальный SDK для сборки.

## Кастомизация

Папка `ThemeKit/Blank` содержит PNG заготовки. `ThemeKit/GraphicDemo.zip` — устанавливаемая тестовая тема. Начните с [инструкции по созданию скина](КАК_СОЗДАТЬ_СКИН.md); полный список размеров — в [ThemeKit/README.md](ThemeKit/README.md). Отчёт о проверке — `TESTING.md`.

## О самом лаунчере

Каталог модов Geode работает через открытый API; для него нужен интернет. Оценки тем, Discord OAuth, Supabase, серверный API и бот пока не реализованы и не подключены. Текущая версия игры устанавливается и обновляется штатным клиентом Steam; старые версии загружаются официальным DepotDownloader через Steam-авторизацию. Автоматический установщик самого Geode пока не добавлен. Некоторые моды требуют дополнительных зависимостей; после скачивания Geode может сообщить об их отсутствии при запуске игры.
