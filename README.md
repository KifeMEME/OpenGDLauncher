# OpenGDLauncher

Бесплатный лаунчер Geometry Dash для Windows 10/11 x64. Исходный код открыт для редактирования. Запуск и базовое использование не требуют учётной записи. Игра устанавливается через Steam, пароль Steam лаунчер не запрашивает и не хранит.

## Внешний вид по скриншотам оригинала

Стандартная тема повторяет основную компоновку присланных скриншотов: компактная верхняя строка, тёмная боковая навигация, крупный заголовок Geometry Dash, центральная карточка с предоставленным изображением `puffi chibi.png` и кнопки выбора версии/запуска внизу. На главной добавлены фиолетовая плашка и крупный текст по последнему макету. Версия игры определяется по журналу установленного Geode; если она неизвестна, отображается `—`. Внешняя рамка рабочей области убрана. Изображения и цвета остаются заменяемыми через PNG-скины.

Приложенный пользователем шрифт `Lemon/Milk(RUS BY LYAJKA)` встроен в тестовую сборку и применяется ко всему интерфейсу. Тема может задать собственный шрифт вместо него. Перед публичным распространением сборки с этим файлом необходимо проверить права на распространение шрифта.

[Скачать тестовую сборку Windows x64](Downloads/OpenGDLauncher-v14-win-x64.zip) (v14, ZIP). Распакуйте архив и запустите `OpenGDLauncher.exe`. Требуется .NET 8 Desktop Runtime. SHA-256 архива: `7B401CC5E2773B9B47ABBB9C079FF704651E0203DC45C3C541B05D2F0784BF8E`.

## Что работает

- Поиск Geometry Dash в библиотеках Steam и ручной выбор папки. Текущая установка запускается через `steam://run/322170`; скачанная через DepotDownloader версия запускается из своей папки. Проверки доступа к игре остаются за Steam и самой игрой.
- При нажатии «Играть» запрос всегда передаётся клиенту Steam. Если локальная запись установки отсутствует, показывается информационная плашка с переходом в Steam и на страницу покупки; она не блокирует запуск и не считается доказательством отсутствия покупки.
- Открытие Steam для законной установки и обновления игры.
- Список реально установленных модов Geode из папки `geode\mods`: название, иконка `logo.png`, автор и версия. По умолчанию открывается папка игры, которую запускает лаунчер; через список можно переключиться на папку версии прежнего лаунчера в `%LOCALAPPDATA%\GDLauncherSteam\versions`.
- Отдельный каталог «Моды» во вкладке Geode: поиск, страницы, просмотр всех или совместимых модов, иконки и скачивание из официального индекса Geode. Папка загрузки видна в интерфейсе. Скачанный архив проверяется по SHA-256 и манифесту, затем сохраняется в выбранную папку; несовместимые с определёнными версиями игры и Geode моды нельзя скачать.
- Левый нижний блок Steam открывает панель QR-входа. Пользователь вводит логин Steam, подтверждает QR в мобильном приложении один раз; сеанс DepotDownloader сохраняется зашифрованным средствами Windows для следующих загрузок. В панели можно выйти. Логин сам по себе не подтверждает покупку: доступ к игре проверяет Steam.
- Размер окна зафиксирован на 1000×670; стандартный `hero.png` заменён на предоставленный `puffi chibi.png`.
- На главной убраны логотип из боковой панели, строка `GEOMETRY DASH / PC` и блок статуса игры; путь и состояние установки доступны во вкладке Geometry Dash.
- При щелчке по картинке на главном экране она слегка сжимается по вертикали и возвращается обратно, одновременно воспроизводится приложенный звук `awee.wav`.
- Кнопка на главной открывает каталог версий. Для версий с указанным Steam-манифестом кнопка «Скачать» запускает официальный DepotDownloader 3.4.0 с сохранённым Steam-сеансом. В окне видны полоса загрузки, процент и имена обрабатываемых файлов. Каждая версия загружается в собственную папку `%LOCALAPPDATA%\OpenGDLauncher\Versions`. Выбор скачанной версии запускает EXE именно из её папки; для текущей установки Steam обычный запуск остаётся через клиент Steam. Доступ к старым манифестам определяется Steam и разработчиком игры. Подробности — в [инструкции по версиям](КАК_СКАЧАТЬ_ВЕРСИЮ.md).
- Русский и английский интерфейс; настройки хранятся в `%APPDATA%\OpenGDLauncher\settings.json`.
- Локальные темы из `Themes/<имя>/theme.json`, безопасный импорт ZIP в «Настройках», применение и удаление в «Мои темы».
- Темы теперь оформляют также плашку главной, строки модов, окно выбора версий, Steam-блок, поля ввода и звук персонажа. Шаблоны и подробная инструкция доступны кнопкой в «Настройках» и включены в тестовый архив.
- Кнопка «Поддержать автора» в разделе «Описание» открывает DonationAlerts. Пожертвование добровольное.

## Сборка

Откройте `OpenGDLauncher.sln` в Visual Studio 2022 с компонентом **.NET desktop development** и .NET 8 SDK. Выберите `Release` и соберите решение. Альтернатива: `dotnet publish Launcher.UI/Launcher.UI.csproj -c Release -r win-x64 --self-contained false`.

Тема по умолчанию создаётся при первом запуске в `%APPDATA%\OpenGDLauncher\Themes`. Для самостоятельного распространения скопируйте всю папку публикации. Нужен установленный .NET 8 Desktop Runtime. Не переносите папку `.dotnet`, если она есть в исходном проекте: это только локальный SDK для сборки.

## Структура

`Launcher.Core` — игра, Steam, настройки. `Launcher.Themes` — манифест и валидация скинов. `Launcher.Workshop` — безопасный локальный импорт. `Launcher.UI` — WPF.

## Комплект дизайнера

Папка `ThemeKit/Blank` содержит PNG заготовки. `ThemeKit/GraphicDemo.zip` — устанавливаемая тестовая тема. Начните с [инструкции по созданию скина](КАК_СОЗДАТЬ_СКИН.md); полный список размеров — в [ThemeKit/README.md](ThemeKit/README.md). Отчёт о проверке — `TESTING.md`.

## Ограничения текущего этапа

Оригинальный EXE и извлечённые из него ресурсы в публичный репозиторий не входят. Каталог модов Geode работает через открытый API; для него нужен интернет. Оценки тем, Discord OAuth, Supabase, серверный API и бот пока не реализованы и не подключены. Текущая версия игры устанавливается и обновляется штатным клиентом Steam; старые версии загружаются официальным DepotDownloader через Steam-авторизацию. Лаунчер не обходит DRM. Не для каждой версии известен Steam-манифест, и Steam может закрыть доступ к старому манифесту. Автоматический установщик самого Geode пока не добавлен. Некоторые моды требуют дополнительных зависимостей; после скачивания Geode может сообщить об их отсутствии при запуске игры.

## Безопасность тем

ZIP допускает только `theme.json`, PNG и необязательный `hero.wav`, ограничен 100 файлами и 50 МБ распакованных данных. Путь каждого файла проверяется, исполняемые файлы и скрипты не импортируются. Изображения в манифесте проверяются по сигнатуре и размерам; WAV проверяется по заголовку и ограничен 5 МБ. Не устанавливайте темы в папку игры.
