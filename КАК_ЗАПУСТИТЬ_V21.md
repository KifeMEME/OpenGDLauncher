# Запуск OpenGD Launcher v21 на Windows 10 x64

1. Распакуйте **весь** архив в обычную папку. Не запускайте EXE прямо из ZIP.
2. Если на компьютере ещё нет **.NET Desktop Runtime 8 (Windows x64)**, установите его с [официального сайта Microsoft](https://dotnet.microsoft.com/en-us/download/dotnet/8.0). Нужен именно раздел *Desktop Runtime*, а не SDK.
3. Запустите `OpenGDLauncher.exe`.

Папка `Videos` должна находиться рядом с EXE. В ней лежат семь коротких фрагментов уровней; они меняются на главной карточке примерно каждые 10 секунд и воспроизводятся без звука. Если убрать MP4, останется обычный фон темы. Порядок меняется в `Videos/playlist.txt`.

Предпросмотр можно отключить кнопкой рядом с «Выбрать версию». Выбор сохраняется в отдельном файле `%APPDATA%\OpenGDLauncher\preview.json` и действует после следующего запуска. Если включить его обратно, видео сразу возобновится.

При открытии плашки входа Steam видео временно останавливается, чтобы не перекрывать её. После закрытия входа предпросмотр возвращается автоматически, если он включён в настройке.

Для звуков кнопок предусмотрена папка `Sounds` рядом с EXE. Пока звуков в сборке нет. Если позже положить туда `button-hover.wav` и `button-click.wav`, при наведении и нажатии кнопки будут звучать соответствующие файлы. Подробности — в `Sounds/README.md`.

Для обновления с прошлой версии распакуйте новую сборку в отдельную папку. Настройки пользователя и скачанные версии игры хранятся отдельно от EXE. Не удаляйте свои папки с игрой и модами.

Для сборки из исходников откройте `OpenGDLauncher.sln` в Visual Studio с .NET 8 или выполните `dotnet publish Launcher.UI/Launcher.UI.csproj -c Release -r win-x64 --self-contained false`.
