# Видео на главной карточке

Положите записи уровней в эту папку в формате MP4 (H.264). Имена файлов и порядок указаны в `playlist.txt`. Лаунчер показывает каждый ролик без звука под полупрозрачным (50%) слоем цвета карточки и плавно переключает их примерно каждые 10 секунд. Если ролик короче, раньше переключается на следующий. Если подходящих файлов нет или видео не воспроизводится, остаётся обычный фон темы.

Показ можно выключить кнопкой «Отключить предпросмотр» рядом с выбором версии и снова включить кнопкой «Возобновить предпросмотр». Состояние сохраняется в отдельном файле `%APPDATA%\OpenGDLauncher\preview.json`. При желании файл можно открыть Блокнотом: `"enableVideoPreview": false` выключает видео, `true` включает. После ручного изменения перезапустите лаунчер. Если `%APPDATA%` недоступна для записи, используется `UserData\preview.json` рядом с EXE.

В `playlist.txt` указаны семь уровней из топ-20 [Pointercrate Demonlist](https://pointercrate.com/demonlist/) по состоянию на 10 ноября 2026 года. Рейтинг может измениться. Можно заменить список своими именами MP4; допускается до 20 строк. Указывайте только имя файла, без пути. Для включения чужих записей в распространяемую сборку получите разрешение их авторов.
