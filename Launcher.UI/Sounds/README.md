# Звуки кнопок

Положите сюда свои WAV-файлы:

- `button-hover.wav` — наведение на активную кнопку;
- `button-click.wav` — нажатие кнопки мышью или с клавиатуры.

Оба файла необязательны. Если файла нет, кнопка работает без звука. После добавления файлов перезапустите лаунчер. Звуки должны быть в формате WAV (RIFF/WAVE); сейчас в комплекте нет готовых звуков.

Для отдельного скина можно положить WAV в папку темы и указать относительные пути в `theme.json` через поля `buttonHoverSound` и `buttonClickSound`. Если файл темы отсутствует, лаунчер использует файл стандартной темы или эту папку `Sounds`.
