# Звуки лаунчера

В сборке находятся три звука, подготовленные из MP3-файлов автора:

- `launch.wav` — открытие главного окна;
- `button-hover.wav` — наведение на активную кнопку;
- `button-click.wav` — нажатие кнопки мышью или с клавиатуры.

Звуки необязательны: если удалить файл, лаунчер продолжит работать. Чтобы заменить звук без правки кода, замените соответствующий WAV и перезапустите лаунчер. Исходные MP3 сохранены в `SoundSources` репозитория; для работы в лаунчере нужен WAV (RIFF/WAVE).

Для отдельного скина можно положить WAV в папку темы и указать относительные пути в `theme.json` через поля `launchSound`, `buttonHoverSound` и `buttonClickSound`. Скрипт `ThemeKit/create-theme.ps1` запишет эти поля автоматически. Если файл темы отсутствует, лаунчер использует файл стандартной темы или эту папку `Sounds`.
