# Компоненты видеоплеера

Для воспроизведения фона используются [LibVLCSharp.WPF 3.10.2](https://www.nuget.org/packages/LibVLCSharp.WPF/3.10.2), [LibVLCSharp 3.10.2](https://www.nuget.org/packages/LibVLCSharp/3.10.2) и [VideoLAN.LibVLC.Windows 3.0.24](https://www.nuget.org/packages/VideoLAN.LibVLC.Windows/3.0.24). Их пакеты указывают лицензию [LGPL-2.1-or-later](https://www.gnu.org/licenses/old-licenses/lgpl-2.1.html). Исходный код доступен в [репозитории LibVLCSharp](https://github.com/videolan/libvlcsharp) и [репозитории libvlc-nuget](https://code.videolan.org/videolan/libvlc-nuget).

В ZIP-сборке DLL этих библиотек остаются отдельными файлами. Их можно заменить совместимыми версиями. Из пакета VideoLAN включены только бинарные компоненты Windows x64.

Сведения об исходных видеороликах и времени нарезки находятся в `Videos/README.md`.
