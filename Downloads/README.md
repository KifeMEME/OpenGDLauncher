# Тестовые сборки OpenGDLauncher

**Актуальная сборка:** [OpenGDLauncher v17 для Windows x64](OpenGDLauncher-v17-win-x64.zip). Распакуйте ZIP и запустите `OpenGDLauncher.exe`. Нужен установленный .NET 8 Desktop Runtime.

В v17 кнопки плавно заполняются цветом слева направо при наведении. Для графических тем используется изображение `hover.png`, поэтому оформление и анимация работают вместе.
