# Загрузка версий Geometry Dash

## Что понадобится

- Windows 10/11 x64, интернет и аккаунт Steam с правом на Geometry Dash.
- Мобильное приложение Steam для подтверждения входа по QR-коду.
- Свободное место для каждой выбранной версии игры. Старые сборки сохраняются отдельно от установки Steam.

## Как скачать

1. Нажмите на блок **Steam** в левом нижнем углу. Введите логин Steam, нажмите **«Войти по QR»** и подтвердите код в мобильном Steam. Это требуется один раз для последующих загрузок, пока сеанс действителен. При необходимости в этой же панели можно выйти.
2. Нажмите **«Выбрать версию»** на главной. Выберите версию, у которой указан Steam-манифест, и нажмите **«Скачать»**.
3. При первом использовании лаунчер получит официальный DepotDownloader 3.4.0 с GitHub. Архив проверяется по заранее закреплённому SHA-256. Если эта версия DepotDownloader уже есть в кэше прежнего лаунчера, она будет использована только после той же проверки.
4. Во всплывающем окне выбора версий видны небольшая полоса загрузки, процент по завершённым файлам и имя текущего файла. Steam проверяет доступ к депо.
5. После успешной загрузки карточка получит статус **«Загружена»**. Нажмите **«Выбрать»**, затем **«Играть»**. Лаунчер запустит `GeometryDash.exe` именно из папки выбранной версии. Если игра быстро завершится, лаунчер покажет сообщение.

Кнопка закрытия каталога отменяет текущую загрузку. При повторной попытке DepotDownloader проверяет уже сохранённые файлы и продолжает работу. Файлы версий находятся в `%LOCALAPPDATA%\OpenGDLauncher\Versions\<номер версии>`; сам инструмент — в `%LOCALAPPDATA%\OpenGDLauncher\DepotDownloader-3.4.0`.

## Учётная запись и доступ

Лаунчер не спрашивает пароль Steam и не передаёт его в аргументах процесса. Вход по QR выполняет DepotDownloader. Полученный сеанс лаунчер шифрует через Windows DPAPI в `%APPDATA%\OpenGDLauncher\steam-auth.json`; прочитать его может только тот же пользователь Windows. DepotDownloader временно записывает токен в своё хранилище во время работы. После завершения лаунчер восстанавливает прежнее состояние этого хранилища. Не запускайте два экземпляра DepotDownloader одновременно. Если Steam отзовёт сеанс, повторите вход по QR.

Для скачивания и запуска игры требуется законное право доступа в Steam. Лаунчер не изменяет исполняемый файл, не обходит Steam и не подменяет проверку права владения. Steam или разработчик могут ограничить скачивание прежнего манифеста даже владельцу игры. В таком случае выберите доступную версию или пользуйтесь текущей установкой Steam.

Для версий **1.91, 1.92 и 2.1** Steam-манифест не задан, поэтому кнопка загрузки отключена. Номер манифеста у остальных версий означает лишь известный идентификатор; фактическая доступность подтверждается только ответом Steam. Geode и конкретные моды могут быть несовместимы с выбранной старой версией.

## Если возникла ошибка

- **Не появился QR-код:** откройте блок Steam слева внизу, введите логин аккаунта Steam и нажмите «Войти по QR». Код появится внутри этой панели.
- **Ошибка авторизации или доступа к манифесту:** убедитесь, что вошли в Steam-аккаунт с игрой. Если Steam не отдаёт старый манифест, лаунчер не может снять это ограничение.
- **Загрузка прервалась:** откройте каталог и нажмите «Скачать» ещё раз. Ключ `-validate` проверит уже скачанные файлы.
- **Игра не запускается:** убедитесь, что Steam работает и нужный аккаунт активен. Для проверки самого лаунчера попробуйте текущую версию, установленную Steam.

Steamworks может перенаправлять прямой запуск старой игры на текущую установленную сборку Steam. Лаунчер создаёт в папке скачанной версии штатный `steam_appid.txt` с ID игры `322170`, как описано в документации Steamworks. Это не отключает проверку права владения. На тестовой машине старая версия 1.9 запускается из правильной папки, но затем аварийно завершается в `libcocos2d.dll`; эту ошибку самой старой сборки исправить в лаунчере пока не удалось.

Официальный проект: [SteamRE/DepotDownloader](https://github.com/SteamRE/DepotDownloader). Его лицензия GPL-2.0 включена в загружаемый архив. В тестовой сборке сам DepotDownloader не распространяется: он загружается при первом использовании функции.
