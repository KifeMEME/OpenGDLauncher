# Комплект для оформления OpenGDLauncher

Начните с [пошаговой инструкции](../КАК_СОЗДАТЬ_СКИН.md). Здесь перечислены все графические файлы актуального интерфейса. Тема меняет оформление, но не меняет расположение элементов и работу кнопок.

## Файлы комплекта

- `Blank/` — 30 прозрачных PNG нужных размеров и образец `hero.wav`.
- `layout-guide.png` — схема главного окна 1000×670.
- `version-layout-guide.png` — схема окна выбора версий 720×630.
- `mod-row-layout-guide.png` — разметка строки мода Geode 710×70.
- `GraphicDemo/` и `GraphicDemo.zip` — работающий пример графического скина.
- `create-theme.ps1` — создаёт папку темы, `theme.json` и ZIP из PNG без ручного написания JSON.

`hero.wav` — звук при щелчке по персонажу. Можно заменить файлом WAV до 5 МБ или отключить через `heroSoundEnabled: false` в `theme.json`.

`logo.png`, `icon.png`, `decoration.png` остаются для совместимости старых скинов. В текущем окне эти три изображения не отображаются. Текст кнопок и названия версий рисует приложение, поэтому в PNG кнопок не пишите слова — они должны работать и на русском, и на английском.

При наведении слой `hover.png` открывается поверх `normal.png` слева направо примерно за 0,24 секунды и скрывается при уходе указателя. Изображение остаётся в полном размере: анимация открывает его часть, не растягивая рисунок. Это работает для навигации, основных кнопок, карточек и кнопок выбора версии. `pressed.png` появляется сразу при нажатии, чтобы состояние нажатия было заметным.

## Координаты главного окна

- Шапка: x=0, y=0.
- Кнопка языка: примерно x=909, y=4; PNG флага внутри неё — 24×16.
- Боковая панель: x=0, y=34.
- Основная область: x=228, y=50.
- Главная карточка: x=228, y=130.
- Плашка внутри карточки: приблизительно x=241, y=144.
- Кнопки внизу: x=517 и x=747, y=571.
- Steam: x=12, y=586.

Для точного размещения используйте `layout-guide.png` поверх слоёв в Photoshop. В окне версий первые четыре карточки начинаются примерно с x=28, y=164; шаг по горизонтали 168, по вертикали 56. Кнопка «Выбрать» находится примерно по x=529, y=555.

## Технические пределы

Изображения — только PNG, максимум 4096×4096 и 10 МБ на файл. Один ZIP — не более 100 файлов и 50 МБ в распакованном виде. Отсутствующий PNG берётся из стандартной темы. В темах не запускается код. Большие изображения масштабируются с сохранением пропорций; края могут обрезаться в элементе другого размера, поэтому лучше экспортировать по таблице.
